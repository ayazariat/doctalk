DocTalk – Assistant Médical Intelligent
Description

DocTalk est un assistant médical intelligent capable de simuler une consultation, d’analyser les symptômes et de fournir des recommandations de santé. Le projet combine une interface web interactive avec des modules de traitement du langage naturel (NLP) pour offrir une expérience utilisateur fluide et intuitive.

L’objectif principal est de fournir un outil d’aide à la décision médicale pour les utilisateurs tout en permettant aux développeurs de se familiariser avec les concepts de NLP et d’IA appliqués à la santé.

Fonctionnalités

Interface web interactive pour saisir les symptômes.

Analyse des symptômes avec un module NLP.

Simulation de consultation médicale automatisée.

Suggestions et conseils basés sur les informations saisies.

Documentation complète des étapes de conception et d’expérimentation.

Technologies Utilisées

Front-end : HTML, CSS, JavaScript, Bootstrap

Back-end : Python

Intelligence Artificielle / NLP : Python (bibliothèques NLP, analyse de texte)

Outils : VS Code, Git/GitHub

Méthodologie : UML pour modélisation des cas d’utilisation et diagrammes de classes

Installation

Cloner le repository :

git clone https://github.com/ayazariat/doctalk.git



Usage

Saisir les symptômes dans l’interface web.

L’assistant analyse les entrées et fournit un diagnostic simulé.

Les résultats sont affichés avec des recommandations basiques et des explications sur les analyses.
